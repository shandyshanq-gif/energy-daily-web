# 衍生指标口径文档

> **版本**: v1.0 | **创建日期**: 2026-08-02 | **适用项目**: 能源日报 Web 前端

---

## 一、文档目的

本文档定义能源日报系统中所有衍生指标的计算口径、数据来源和统计周期，确保同一指标在不同日报中计算方式一致，避免因口径歧义导致的数据偏差。

---

## 二、指标定义

### 2.1 同比（Year-over-Year, YoY）

**定义**: 本期值与去年同期值的相对变化率。

**公式**:
```
同比 = (本期值 - 去年同期值) / 去年同期值 × 100%
```

**示例**:
- 2026-08-02 WTI 价格 84.67 美元/桶
- 2025-08-02 WTI 价格 67.35 美元/桶
- 同比 = (84.67 - 67.35) / 67.35 × 100% = 25.71%

**数据来源**: TradingEconomics（原油、天然气）、CCTD（煤炭）、SHPGX（LNG）

**统计周期**: 自然日，本期与去年同期均为同一日历日（若去年同期非交易日，取最近的交易日数据）

**特殊处理**:
- 去年同期值为 0 或缺失时，同比标记为 "N/A"
- 去年同期值与本期值单位必须一致

---

### 2.2 环比（Month-over-Month, MoM）

**定义**: 本期值与上一期（上月末）值的相对变化率。

**公式**:
```
环比 = (本期值 - 上期值) / 上期值 × 100%
```

**示例**:
- 2026-08-02 WTI 价格 84.67 美元/桶
- 2026-07-31 WTI 价格 79.85 美元/桶
- 环比 = (84.67 - 79.85) / 79.85 × 100% = 6.04%

**数据来源**: 同同比

**统计周期**: 自然月，上期值为上月最后一个交易日的收盘价

**特殊处理**:
- 上期值为 0 或缺失时，环比标记为 "N/A"
- 跨月时以上月最后一个交易日为基准

---

### 2.3 涨跌幅（日涨跌，Daily Change）

**定义**: 最新价与前日价（上一交易日）的相对变化率。

**公式**:
```
涨跌幅 = (最新价 - 前日价) / 前日价 × 100%
```

**示例**:
- 2026-08-02 WTI 收盘价 84.67 美元/桶
- 2026-08-01 WTI 收盘价 83.59 美元/桶
- 涨跌幅 = (84.67 - 83.59) / 83.59 × 100% = 1.29%

**数据来源**: 同同比

**统计周期**: 交易日，前日价为上一个实际交易日（跳过周末和节假日）

**特殊处理**:
- 前日价为 0 或缺失时，涨跌幅标记为 "N/A"
- 周一或节假日后的第一个交易日，前日价为上一个交易日
- 日报中的箭头标记：↑ 表示上涨，↓ 表示下跌，→ 表示持平

---

### 2.4 月涨跌（Monthly Change）

**定义**: 当月最新价与月初价的相对变化率。

**公式**:
```
月涨跌 = (当月最新价 - 月初价) / 月初价 × 100%
```

**示例**:
- 2026-08-02 WTI 价格 84.67 美元/桶
- 2026-08-01 WTI 价格 83.59 美元/桶（月初）
- 月涨跌 = (84.67 - 83.59) / 83.59 × 100% = 1.29%

**数据来源**: 同同比

**统计周期**: 自然月，月初价为当月第一个交易日的收盘价

## 四、前端解析规则

### 4.1 日报 Markdown 中的指标格式

日报 Markdown 中，衍生指标以文本形式嵌入价格表格：

| 表头 | 示例值 | 含义 |
|:-----|:-------|:-----|
| 价格 | `**84.67**` 或 `**21.45** 美元/百万英热` | 最新报价（含粗体标记和单位后缀） |
| 日涨跌 | `↑ 1.29%` 或 `↓ -0.40%` 或 `-> 0` | 涨跌幅（含方向箭头） |
| 月涨跌 | `23.46%` | 月涨跌幅（纯百分比） |
| 同比 | `25.75%` | 同比变化率（纯百分比） |

### 4.2 前端提取逻辑

1. **价格提取** (`extractNumericPrice`): 移除 `↑↓▲▼*_$€` 等格式字符后，匹配第一个数字（含小数点）
2. **品种名称归一化** (`normalizeName`): 将日报中的原始品种名称映射到白名单标准名称
   - "Henry Hub" / "HH" → "Henry Hub"
   - "CCTD综合交易5500(平仓价)" → "5500"
   - "CCTD现货交易5000(平仓价)" → "5000"
   - "山西5500(坑口价)" → "山西坑口"
3. **品种白名单过滤** (`isValidSpecies`): 仅保留白名单中的品种，剔除 LNG 区域价格等非标准品种
4. **单位推断** (`inferUnit`): 根据归一化后的品种名称从 `UNIT_MAP` 中查找标准单位

### 4.3 一致性保障

- 同一品种在不同日报中的计算方式必须一致
- 价格数值提取仅取第一个有效数字，避免误解析涨跌幅百分比作为价格
- 品种归一化在 `extractPricesFromReport` 和 `getAllPriceSeries` 中均执行，确保数据一致性
- 白名单与后端 `config.py` 中的品种配置保持同步
